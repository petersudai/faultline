## Summary
This PR adds a fast path optimization to `c.json()` that mirrors the existing optimization in `c.text()`. When no status, headers, prepared headers, or finalized state exist, it uses the standard `Response.json()` API directly instead of going through the full `#newResponse()` path. The change is low-risk because the fast path only triggers in the simplest case (no parameters beyond the object), and `Response.json()` is a standard Web API with well-defined behavior equivalent to the old path.
