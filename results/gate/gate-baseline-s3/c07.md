## Summary
This PR fixes a type-safety issue where `c.body()` was not properly tracking return types in union scenarios, causing type inference to lose information about status codes from other response methods. The fix adds generic type parameters to the `BodyRespond` interface and casts the implementation to match, enabling proper type narrowing in conditional response paths.
