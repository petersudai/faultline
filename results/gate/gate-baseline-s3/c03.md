## Summary
This PR modifies `createMiddleware` to relax TypeScript type constraints for `Bindings` and `Variables` by automatically adding `any` to undefined properties. The change allows nested middleware with partial type specifications to compose without type errors. The main risk is that this type relaxation could mask legitimate type mismatches and reduce type safety in middleware composition.
