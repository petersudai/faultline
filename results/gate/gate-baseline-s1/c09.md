## Summary

## Findings (3)

### 🟡 Medium — src/helper/adapter/index.ts:16 — api-contract

The parameter type changed from `c: C` to `c: T extends Record<string, unknown> ? Context : C`. This conditional type is unusual and may cause unexpected behavior. When `T` is provided (which it always is, since it's a required generic), the parameter type becomes `Context` instead of the more specific `C`. This could break type safety for callers who rely on `C` being the actual context type passed in.

→ Check: Verify that the conditional type `T extends Record<string, unknown> ? Context : C` actually improves type inference in practice. While semantically equivalent (the empty intersection `{} &` is redundant), this is a type-level change that could affect type inference in edge cases or when consumers rely on the exact shape of the default type.
