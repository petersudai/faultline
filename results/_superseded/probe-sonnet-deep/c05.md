## Summary
This PR adds a `basePath` option to the `Hono` constructor and deprecates `app.basePath()`, converting internal `_basePath` to a private field `#basePath`. The `route()` method's single-argument overload (used to set base path only) was removed from the type signature but the implementation still supports `route(path)` without an app, which could be a subtle behavior/type mismatch. Constructor now accepts a full options object (`HonoOptions`) replacing the old `Partial<Pick<Hono,...>>` signature — since options like `strict` are deleted via `delete options.strict` and then `Object.assign(this, options)`, mutating the caller-supplied options object as a side effect, which was already present before but worth confirming doesn't leak reference issues since options may be reused by callers.
