## Summary
This PR is primarily a TypeScript type-level fix: `BodyRespond`'s overloads now carry a generic status parameter and return `Response & TypedResponse<...,'body'>` instead of a plain `Response`, so `c.body()` no longer widens/overrides the inferred status-code union for other branches' responses (e.g. `c.text()`, `c.json()`) when building a Hono Client's `$get` schema. The runtime implementation of `body()` is unchanged (same `#newResponse` call path with an added `as ReturnType<BodyRespond>` cast), and a type-test plus a minor test-cleanup were added to validate the fix.
