## Summary
This PR adds a fast path to c.json() mirroring the existing c.text() optimization, using Response.json(object) when no status/headers/finalized state exists. The new fast path relies on the platform's built-in Response.json() implementation instead of the previous manual JSON.stringify + setDefaultContentType flow, which could subtly differ in content-type formatting or error behavior (e.g., BigInt/circular references) compared to the slow path. The existing tests only exercise the slow path (with status/headers args), so the new bare c.json({...}) fast path isn't directly verified for header/content-type parity or correct output.
