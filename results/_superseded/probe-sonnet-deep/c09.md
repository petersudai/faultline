## Summary
This PR is a type-only fix to the `env()` helper's generic signature: it changes the parameter type from `c: C` to `c: T extends Record<string, unknown> ? Context : C`. Since T is always constrained to extend Record<string, unknown>, this always resolves to plain `Context`, relaxing the accepted parameter type while still using `C['env']` for the return type inference from the default. No runtime code paths changed at all — only TypeScript type-checking behavior differs, addressing a documented type-error bug (linked website issue). Tests were updated to cover the three usage patterns (env generic only, Hono generic only, both).
