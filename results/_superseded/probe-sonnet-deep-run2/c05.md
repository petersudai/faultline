## Summary
The PR adds a `basePath` option to the Hono constructor, refactors `_basePath` to a private class field (`#basePath`), and deprecates `app.basePath()`. It also simplifies `route()` to no longer route through the deprecated `basePath()` method, instead cloning and setting `#basePath` directly, and removes the one-argument `route(path)` overload (which was already deprecated for removal in v4). Tests were updated/added to cover the new option alongside existing deprecated usage, but the removal of the distinct one-argument `route()` overload changes its inferred return type at the type level.
