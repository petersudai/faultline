### 🟡 Medium — src/helper/adapter/index.ts — api-contract

The parameter type `c: T extends Record<string, unknown> ? Context : C` is a conditional type where the check condition (`T extends Record<string, unknown>`) will almost always be true since T already has that constraint by default, meaning `c` is typed as generic `Context` regardless of the explicit `C` generic supplied. This could silently widen/narrow inference in ways not fully covered by the added tests, potentially breaking existing use sites that rely on strict typing of `c` against the inferred `C`.
