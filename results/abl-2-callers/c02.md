## Summary
This PR adds a fallback mechanism for environments (like AWS Lambda) where `Response.clone()` is not supported. When cloning fails, it falls back to using `arrayBuffer()` and reconstructs the response. The signature of `generateDigest` is updated to accept both `ReadableStream` and `ArrayBuffer` inputs, and a test is added to verify the fallback works correctly.
