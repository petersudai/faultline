## Summary
This PR adds a fallback mechanism for environments where `res.clone()` is not supported (e.g., AWS Lambda). When `res.clone()` throws an error, the middleware falls back to calling `res.arrayBuffer()` to read the entire response body into memory, then generates the ETag from the buffer. The signature of `generateDigest` is updated to accept both ReadableStream and ArrayBuffer inputs. A test is added for the fallback case.
