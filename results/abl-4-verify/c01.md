## Summary
This PR adds a fast path to `c.json()` using `Response.json(object)` when no status, headers, or finalized state exist, mirroring the `c.text()` optimization. A behavioral difference exists: `Response.json()` sets `Content-Type: application/json; charset=utf-8` while the slow path sets `Content-Type: application/json` without charset. The fast path for `c.json()` lacks explicit test coverage.
