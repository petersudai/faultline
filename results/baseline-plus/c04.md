## Summary
This PR changes runtime detection to use try-catch instead of checking if `navigator` is defined before accessing `navigator.userAgent`. The fix addresses Cloudflare Pages where `navigator` is undefined in production but `navigator.userAgent` can still be accessed. However, the change introduces a potential issue in the `checkUserAgentEquals` function which still directly accesses `navigator.userAgent` without protection.

If `navigator` is undefined or `navigator.userAgent` throws an error in any runtime, this will crash.
