## Summary
This PR adds support for custom hashing algorithms to the ETag middleware by allowing users to provide a `generateDigest` function option. The implementation refactors the digest generation to accept a generator function parameter and defaults to SHA-1 if not provided. A test case validates SHA-256 usage.
