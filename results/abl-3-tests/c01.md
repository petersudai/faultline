## Summary
This PR adds a fast path to c.json() using Response.json(object) when no status, headers, or finalized state exists. The change mirrors an earlier optimization to c.text(). However, there is a critical gap: the fast path uses Response.json() while the slow path uses JSON.stringify() + setDefaultContentType(). While both should set Content-Type to application/json, the fast path is not covered by existing tests, creating risk that subtle differences in header handling or charset encoding could cause behavioral divergence.
