## Summary
This PR adds a fast path to `c.json()` using `Response.json(object)` when no status, headers, or prepared headers exist. The critical issue is a behavioral difference in Content-Type headers: `Response.json()` sets `application/json; charset=UTF-8` while the slow path sets only `application/json`. Additionally, the fast path lacks test coverage for the common case of simple `c.json({...})` calls without arguments, and error handling for non-serializable values may differ between paths.
